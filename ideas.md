# ideas.md

The network will be composed of stations. These stations will have a name, a position, a traffic index, and a number of tracks to accommodate trains. These tracks will be identified by a number or a letter. Each station will also have a unique identifier. We will also note the city to which each station belongs (there can be multiple stations in the same city). Within a station, it will be possible to add/remove a track, and to make a track available/unavailable. It will also be possible to modify the traffic index. If we try, for example, to build the French railway network, then highly trafficked stations like "Paris - Gare de Lyon" will have an index equal to or very close to 1, while less or rarely trafficked stations will have a relatively low index. If we build a network as we wish, we can assign a random value, which could for example follow a normal distribution centered at 0.5.

These stations will be connected to one another by lines. For two stations A and B, we will distinguish the line A->B (from A to B) and the line B->A (from B to A). Note also that these lines will be assumed to be straight: they will therefore represent the segment [AB]. A line has an identifier, possibly a name, as well as a length in km. The identifier of a line could for example be composed as follows: "[station A identifier]-[station B identifier]". A line also has a type: "LVN" if it is a conventional-speed line; "LGV" if it is a high-speed line. A line can be split into 2 lines if a station is added. Formally, suppose we have two stations A and C, and the line A->C. If we add station B such that it is useful to pass through B to travel from A to C, then it is possible to split the line A->C into 2 lines, which are A->B and B->C.

If building the network is the first objective, the second is to be able to use it. It will therefore be possible to carry out journeys using different lines and passing through different stations. A journey will therefore consist of an identifier (handy for referencing those taken regularly), a departure time, a duration (in minutes), a departure station, an arrival station, a price (in game currency). A journey will also be assigned the set of stations passed through during the journey, the stopping time at each of them (except possibly the last one), and the track used. If the stopping track at each station is not yet known at the beginning of the journey, it will be possible to modify it during the journey, provided it is done early enough so that the train can enter the station. Indeed, in a station, the number of tracks that can accommodate trains being limited, it will be impossible for a train to enter the station if no track is available.

Note that, for later perhaps, it will be possible to carry out connections. This will consist of the assembly of several train journeys. A weighting on prices may be applied to obtain a final price lower than the sum of the prices of each journey.
